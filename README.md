## Фичи:
* публикация постов из путешествий с фотографиями, небольшим описанием и привязкой к конкретному месту путешествия;
* оценка и комментарии постов других путешественников;
* подписка на других путешественников, чтобы следить за их активностью;
* поиск популярных мест для путешествий и просмотр постов с этих мест;
* просмотр ленты других путешественников и ленты пользователя, основанной на подписках в обратном хронологическом порядке;

## Требования

### Аудитория приложения

* Число полльзвателей: DAU = $10.000.000$
* Поведение пользователей:
    1. Публикация одного поста в неделю
    2. 1 комментарий в день
    3. 3 реакции в день
    4. 10 раз в день получение актуальной ленты
    5. 1 раз в день получение актуальных мест для путешествия
    6. 1 раз в день просмотр истории
* Регионы использования: страны СНГ

### Особенности приложения

* Сезонность: летом активность пользователей увеличивается в среднем на 50%
* Условия хранения данных: данные храним всегда
* Лимиты и ограничения: 
    1. Максимум 1000 знаков на пост
    2. Максимульное число картинок на пост: 10
    3. Максимальная длина комментария: 140 символов
    4. Максимальное число подписок в сутки 100
    5. Пользователь может оставить максимум 1 реакцию на пост
    6. Максимальное число лайков в сутки: 300
    7. Максимлаьное число комментариев в сутки: 100
    8. Максимальное число постов в сутки: 20
    9. Максимальный размер фотографии: 3 мб
* Временные огриничения:
    1. Создать пост, оставить лайк, коммент, сделать подписку: < 500мс
    2. Поиск места: < 1с
    3. Подгрузка страницы ленты: 1с
    4. Просмотр поста/места: < 1с
    5. Новый пост доходит: для создателя сразу, до подписчкиов может доходить до 10c
    6. Лайки отображается: для оставившего его сразу, в общей статистике до 10м
    7. Комментарий отображается до 500мс для того, кто его оставил
    8. Новая подписка: у подписчика отображается сразу, у человека, на которого делаем фоллоу - до 1м

## RPS

- Создание поста: $10.000.000 * 0.2 * 1.5 / 86400 = 35$ rps
- Комментарий: $10.000.000 * 1 * 1.5 / 86400 = 175$ rps
- Лайк: $10.000.000 * 3 * 1.5 / 86400 = 520$ rps
- Приложить картинку к посту: $10.000.000 * 1.5 / 86400 = 175$ rps (среднее числа картинок к посту = 5)
- Получение ленты: $10.000.000 * 10 * 1.5 / 86400 = 1730$ rps
- Получение рекомендаций мест:  $10.000.000 * 1 * 1.5 / 86400 = 175$ rps
- Получение истории просмотров: $10.000.000 * 1 * 1.5 / 86400 = 175$ rps

## Трафик

### Запись:

- Создание поста: $35 * 4.5 = 158$ kb/s
- Комментарий: $175 * 0.6 = 105$ kb/s
- Лайк: $520 * 0.01 = 6$ kb/s
- Добавление картинки в пост: $175 * 1 = 175$  mb/s

Суммарный трафик 176 mb/s

### Чтение:

- Получение ленты: $1730 * 20 * 4.5 = 150$ mb/s (постранично по 20)
- Получение картинок в ленте: $175 * 20 * 1 = 3500$  mb/s
- Получение рекомендаций мест:  $175 * 20 * 4.5 - 16$ mb/s (постранично по 20)
